Replaces an instructor table. A keyword is just a list of values, not a context or entity – new instructors are added directly by the user in the dropdown.

Note: Alternative to Category 3

INSTRUCTORNAME could also be a free-text field VARCHAR(50) instead of a keyword category. That keeps it at exactly two categories, as in the original requirement.

Price for that: Validation 2 groups by the instructor name. If someone types "Meier" once and "Maier" another time, these count as two different instructors and the 8-hour limit no longer applies correctly. With a keyword, the spelling is guaranteed to be consistent and the instructor still stays in a selection list. Recommendation: keyword.

Validations

onValidation on LICENSECLASS, F_STUDENT

  • Minimum age per LICENSECLASS: AM=16 · A1=16 · A2=18 · A=24 · B196=18 · B=18 · BE=18 · C1=18 · C1E=18 · C=21 · CE=21.
  • Runs on creation and when the class is changed.
  • Message: "Student must be at least {AGE} years old for class {CLASS}."

onValidation on INSTRUCTORNAME, F_LESSON

  • SUM(DURATIONHOURS) of all appointments with the same INSTRUCTORNAME on the same calendar day ≤ 8.
  • Appointments with status CANCELLED do not count.
  • Message: "Instructor {NAME} already has {X} of 8 hours on {DATE}. Please choose a different instructor or time slot."

Actions

ScheduleExam_action

  • On F_STUDENT
  • Checks STATUS = EXAM_PREPARED, otherwise error "Student is not yet ready for the exam"
  • Writes the date to THEORYEXAMDATE, or to PRACTICALEXAMDATE if the theory exam has already been passed
  • Sets STATUS = EXAM_SCHEDULED

BookLesson_action

  • On F_LESSON
  • Shows a message dialog: total hours worked by this instructor (status ≠ CANCELLED) and the resulting earnings calculated from it (hours × hourly-rate constant)

CancelAppointment_action

  • On F_LESSON
  • Sets STATUS = CANCELLED
  • Frees up the hour for the instructor again; counts neither toward the daily limit nor the costs

Calculated Display Value

totalCostPerStudent (No Databank Row needed!)

Not a database field. Calculated when the student record is opened and displayed read-only.

SELECT COALESCE(SUM(DURATIONHOURS), 0) * 85 + 150 + 40
FROM   F_LESSON
WHERE  F_STUDENT_ID = :currentStudent
  AND  STATUS <> 'CANCELLED'

€85 hourly rate, €150 administration fee, and €40 medical certificate are stored as constants in one place in the code. Optional second value: successRate = PASSED ÷ (PASSED + WITHDRAWN) × 100.

Naming Conventions

F_ Driving school (table prefix) · _ID Foreign-key suffix · PK Primary Key · FK Foreign Key · _action Action suffix (CamelCase, no prefix) · _view View suffix · _param Parameter suffix · Keyword containers in CamelCase · validations get no separate name — each is just the field's own onValidation.js

Requirements match: 2 contexts (incl. standard audit fields) · 2 validations · 3 actions · 1 calculated display value · 3 keyword categories.
